SUM RUSH – Project Description

SUM RUSH is an interactive number puzzle game designed to make mathematical thinking fun, fast, and engaging. The game challenges players to select exactly four numbers and combine them to reach a given target sum.

Players can choose from three difficulty categories: SUM OF 100, SUM OF 500, and SUM OF 1000. Once a category is selected, the game presents a set of numbers. Players must identify the correct combination of four numbers and drag them into the designated boxes to achieve the exact target.

The game provides instant feedback through a live sum counter, allowing players to experiment with different combinations and develop their problem-solving skills. After successfully completing a challenge, players can select Next Challenge to continue playing with a new set of numbers.

Key Features
🎯 Three target categories: 100, 500 and 1000
🔢 Nine numbers in each challenge
🖱️ Interactive drag-and-drop gameplay
➕ Real-time sum calculation
🏆 Challenge completion feedback
🔄 Next Challenge and Reset options
📖 Built-in How to Play instructions
📱 Responsive design for desktop, tablet and mobile
🎨 Colourful toon-style visual design
Educational Purpose

SUM RUSH combines game-based learning with basic mathematical reasoning. It encourages players to improve mental calculation, number recognition, logical thinking, concentration, and problem-solving abilities while maintaining a simple and entertaining gameplay experience.
